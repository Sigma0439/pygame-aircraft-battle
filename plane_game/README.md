
## 游戏功能
1. **完整的游戏系统**：菜单、设置、游戏进行、暂停、游戏结束
2. **可调节参数**：玩家速度、子弹速度、敌机速度等
3. **技能系统**：激光束和EMP脉冲波
4. **道具系统**：血包、护盾、反伤道具
5. **能量系统**：随时间充能，击毁敌机充能
6. **难度系统**：简单、中等、困难三个难度

## 运行要求
1. 安装Python 3.6+
2. 安装Pygame库：`pip install pygame`

## 运行方法
1. 将游戏图片放入`assets`文件夹（可选）
2. 运行主程序：`python main.py`

## 控制方式
- **方向键**：移动飞机
- **空格键**：发射子弹
- **Q键**：释放激光束（需要40能量）
- **E键**：释放EMP脉冲波（需要100能量）
- **ESC键**：暂停游戏/返回菜单
- **R键**：重新开始游戏
- **鼠标**：点击菜单按钮

## 游戏图片资源（可选）
将以下图片放入assets文件夹：
- player.png - 玩家飞机
- bullet.png - 玩家子弹
- enemy.png - 敌机
- enemy_bullet.png - 敌机子弹
- laser.png - 激光束效果
- emp.png - EMP效果
- health_pack.png - 血包道具
- shield.png - 护盾道具
- reflect.png - 反伤道具

如果缺少图片，游戏会自动生成替代图形。
